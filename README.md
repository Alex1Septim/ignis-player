# Ignis Player

Музыкальный плеер для Windows. Папки с музыкой становятся плейлистами, обложка крупно на экране, стеклянный интерфейс можно настроить под себя.

Пока программа выходит под рабочим названием **Glint**. Новое название придёт обычным обновлением, медиатека и настройки сохранятся.

## Скачать

Откройте [последний выпуск](https://github.com/Alex1Septim/ignis-player/releases/latest) и выберите файл:

- `Glint-Setup-….exe` — установщик. Установленная программа обновляется сама.
- `Glint-…-portable.exe` — переносная версия, работает без установки. О новых версиях она сообщает, но скачивать их нужно вручную.

Программа пока не подписана сертификатом. Поэтому при первом запуске Windows SmartScreen может показать предупреждение: нажмите «Подробнее» → «Выполнить в любом случае».

В этом репозитории лежат только установщики и обновления.
